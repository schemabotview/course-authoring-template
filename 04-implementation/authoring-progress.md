# Authoring progress template

- Status: Not started
- Plan revision: Set when a subject course plan exists

## Course status

Populate from the approved course plan. For each course record section IDs, authoring state, technical verification, visual review, and pending work.

## Section records

Record section ID, authoring state (Scaffold/Drafted/Author-checked/Reviewed), sources checked, technical environment and actual results, visual checks, reviewer/date, and unresolved items as work occurs.

## Continuity notes

Record recurring story entities, terminology, environment assumptions, and decisions needed across sections. No subject-specific choices are preselected.
